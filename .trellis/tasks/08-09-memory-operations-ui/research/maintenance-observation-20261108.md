## 4. Trade-offs

1. **Observation replaces boot profiling.** It captures the missing window without overlapping two profilers. Boot-only attribution is unavailable in this flagged run; unflagged L2–L4 remain the existing baseline path.
2. **Cost estimate, not measured overhead:** the same 1,000 µs V8 sampling interval is retained for longer. Linear scaling from the legacy 62.78 MiB/60.23 s artifact suggests roughly **125–155 MiB for 120–150 s**, and **375 MiB at six minutes**; stack diversity makes this an estimate, not a byte cap. V8/profile serialization may need several times the artifact size in memory. Additional work is 40 small timer/IPC observations per second, two Core request metadata messages and two Native ASGI log entries per request, plus fence snapshots. The percentage CPU overhead is **UNKNOWN without a paired measurement**; expect nonzero overhead and do not use this mode as the timing baseline. Serialization is after the measured window, before backup.
3. **Clock and stall meaning:** inspector start has a measured handshake bracket; absolute stack times carry that uncertainty. The 25 ms loop probe measures timer lateness, not exact blocking onset. Sample-weighted non-idle stretches include program/GC/scheduling effects and are not OS CPU accounting.
4. **Metadata-only logs lose ordinary diagnostic prose.** This is confined to opt-in task adapters. Actual response bytes still reach Core/Native unchanged; only diagnostic serialization is projected. Runtime fixture DBs/backups retain their required data semantics.
5. **Native server and client spans are different measurements.** ASGI elapsed spans include sending/background completion; Core spans include transport and event-loop delay. The histogram counts requests started inside the window, reports full measured total/max duration and clipped `windowMs`, and separates requests crossing the end from requests with no observed completion. Unobserved durations are not zeros. Legacy counts remain whole-run only.
6. **No new entry instrumentation for unavailable timeline boundaries.** Curator/slot/tool/refresh exact edges remain UNKNOWN. Durable completion bounds and sampled frames are explicitly weaker evidence.
7. **A six-minute cap is not fence release.** No backup is attempted without proven free state. If Core cannot answer inspector/IPC after the cap, collection fails explicitly; the existing replay's independent chat and shutdown budgets still govern overall process lifetime.
8. **Task loader anchors couple to source text.** Exact-match assertions fail loudly after helper/source drift. No shared helper, production source, prompt/template or protocol was edited. The added helper hashes preserve which observation code the leader actually ran.
9. **The regression shortens only its fixture wait.** It tests actual timeout handling and retry with real fixture state, not performance or timer starvation. It cannot substitute for wave B's full-window run or owner Home acceptance.
