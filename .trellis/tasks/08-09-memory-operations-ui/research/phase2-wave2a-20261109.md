## 4. Trade-offs

- **Current eligible backlog rather than a second persisted discovery watermark.** The schedule obligation is durable, but discovery restarts from the beginning after interruption. Existing deterministic item admission/results prevent replay and each local cursor advances only after COMMIT. New eligible versions can join an unfinished obligation, and sustained changes can delay its completion. This intentionally avoids duplicating item progress in a new page/high-water journal; it costs rereads on resume. [source packages/core/src/memory/hindsight/hindsight-policy-curator.ts:117] [inference]
- **Stable complete inventory.** Pages use existing verified eligibility and yield between 32 accepted candidates. A changing checkpoint invalidates the count and rearms a retry. This preserves UNKNOWN versus empty, but large/changing Banks can incur repeated scans. Per-page decoding still runs on Core. [source packages/core/src/memory/hindsight/hindsight-policy-review-inventory.ts:29] [inference]
- **Scoped invalidation.** Replica changes invalidate only their Bank; chat idle only rearms paused obligations. Configuration/startup still scan all routed Banks. Existing bounded scheduler wakes notice User Timezone changes when there is no separate timezone writer notification. [source packages/core/src/memory/hindsight/hindsight-policy-schedule.ts:57] [source packages/core/src/memory/hindsight/hindsight-policy-schedule.ts:163]
- **Five-second idle admission.** Character review waits for that Character; Global waits for all active turns. New chat may overlap an already started review. This favors foreground admission but does not claim preemption or invisible CPU work. [source packages/core/src/memory/hindsight/hindsight-policy-schedule.ts:16] [inference]
- **Manual-only sync stays manual-only.** Review operates on committed bound replica versions and does not implicitly pull remote changes. Newly retained remote facts become threshold inputs after a real replica application. Explicit operator tidy retains its existing diagnostics/result contract; automatic and scheduled review bypass that enumeration. [source packages/core/src/memory/hindsight/hindsight-memory-subsystem.ts:169] [inference]
- **Saved-result guarantee only.** A response lost before its first durable save can require another model call. A saved result always follows original command recovery, including after an unknown dispatch outcome. Existing retry delays may postpone recovery until claim expiry or a future failed-assessment deadline. [source packages/core/src/memory/hindsight/hindsight-policy-curator.ts:142] [source packages/core/src/db/hindsight-policy-work-progress.ts:13]
- **Status compatibility and honesty.** `review` is optional for older wire producers; current Core supplies it. Null state means idle; null eligible count means UNKNOWN. Saved-awaiting-publication includes policy and Block results until their item is terminal. Catch-up identity remains after completion for wave 2b notice consumption. [source packages/shared/src/memory-authority-status-schema.ts:51] [source packages/core/src/db/hindsight-policy-review-repo.ts:53]
