original-data access, dependency change, or full-stack/manual acceptance occurred.

`hindsight-backup-service.ts` now gives its existing single `writeFence.quiesce`
120,000 ms by default, instead of 30,000 ms, and passes the service AbortSignal.
There is no retry/reopen loop. Existing admitted parents and nested children keep
their normal counted lifetimes while new writes are refused. After they drain,
the same capture continues using its original operation and backup identities.
The explicit `quiesceTimeoutMs` override remains available. Native capture retains
its separate 600,000 ms default deadline and existing deadline race.

Cancellation during admission uses the existing failure vocabulary: ordinary
service stop returns `HINDSIGHT_BACKUP_NATIVE_FAILED`; epoch retirement returns
`MEMORY_AUTHORITY_MISMATCH`. Neither starts identity capture, Core copy, Native
snapshot or scheduler stop. The actual fence preserves irreversible retirement;
the backup service does not release/reopen it after a failed admission. Existing
post-admission cleanup, scheduler release/restart and emergency evidence retention
contracts remain in place.

Home's existing phase now says `暂停新写入，限时等待已有记忆处理结束`.
Timeout reports that waiting expired without creating a backup and offers a fresh
operator retry after the work settles. The existing Native failure code at the
`quiescing` phase reports `备份等待被中断，本次未创建备份`; failures at Native
capture keep their original wording. No countdown, polling, new protocol or
visual layout was introduced.

## Tradeoffs and remaining work

- Admission can refuse new memory writes for up to 120 seconds instead of 30.
  This increases tolerance for already admitted work; no speedup was measured,
  and arbitrary work is not guaranteed to finish within that budget.
- The 120 seconds bounds admission only. Subsequent Core copy and the separate
  Native capture budget remain part of the existing paused window; this is not a
  120-second bound for the complete capture or its entire write-refusal duration.
- Shutdown interrupts admission promptly but retains its existing joining and
  cleanup behavior after capture begins. Retirement retains existing detached,
  epoch-scoped behavior and preserves emergency evidence.
- Ordinary stop retains the broad existing Native failure code. Home uses the
  producer's actual phase to disclose an interrupted wait without suggesting a
  Native snapshot had begun.
- Integrated serial typechecks, independent whole-wave review and leader-owned
  spec/index/phase updates remain. Real concurrent maintenance/backup, the actual
  Native service and installed/browser/manual acceptance remain unperformed.
  The owner must arrange memory before any full-stack verification; the current
  wave plan cites about 6 GiB available physical memory for one stack.
