### 3. D78 raw staging is not a ready B5 reader

`packages/core/src/db/hindsight-replica-repo.ts:50-52` persists normalized native `record.payload.value` into raw staging. `:71-87` publishes `hindsight_replica_records` and `hindsight_replica_checkpoints`. The repository's public reads expose identity/revision/hash summaries (`:20-26`), not canonical recall records.

D78 validates certificate-bound pages and publishes this raw representation via `publishHindsightCurrentReplica` (`packages/core/src/db/hindsight-current-replica-publication.ts:12-43`). It can reconstruct the same raw state from retained local evidence and refuses a stale certificate over a newer cursor.

B5 uses a different schema, complete canonical payloads and its own transactional checkpoint/FTS. `seedVerifiedSnapshot` projects every native object before publication (`packages/core/src/db/hindsight-replica-sync-repo.ts:71-81`). The missing bridge must establish trusted D77 projections for the complete snapshot and seed B5 through this guarded API; pointing runtime recall at the raw B4 table does not satisfy that contract.

### 4. Exact D77 evidence/preservation gaps

1. **The current projection is immutable and version-specific.** `createHindsightSourceEvidenceProjection` looks up the complete provider-lineage / bank-generation / bank / object-kind / object-ID / object-revision key, refuses a missing binding, compares the exact native payload hash and requires its prepared Local evidence (`packages/core/src/memory/hindsight/hindsight-source-evidence-projection.ts:42-58`). It never adopts the nearest old binding after an external edit.
2. **Typed source and unit metadata are separate.** Source metadata/context/provenance are restored from prepared source evidence (`:31-36`); a memory uses its explicitly associated Local unit (`:61-71`). The native layer tag must uniquely match that unit's policy. One-to-many extraction does not authorize cloning a source policy onto every new native fact.
3. **Legacy string encoding remains a real version boundary.** `hindsight-pending-client.ts:76-81` keeps strings and canonical-JSON encodes non-strings. `hindsight-source-evidence-projection.ts:74-75` compares that exact v1 map before restoring types. D78 already transfers typed JSON; its representation must get a distinct supported projection path rather than globally rewriting frozen G1/v1 commands or parsing arbitrary native strings as JSON.
4. **D78 retains full Taki artifacts locally, but does not send their bodies as native logical objects.** `hindsight-current-capture-reader.ts:38-40` captures full records and all dispositions; `:64-68` classifies policy, Blocks and other non-native rows as `taki-artifact`. `hindsight-current-request.ts:32-35` explicitly removes source provenance and submits only `record.unit` for native units. The source witness (`:56-57`) hashes the complete Local object; a hash proves identity but cannot reconstruct the omitted policy/provenance body after all Local evidence is lost.
5. **Raw reseeding and total Local evidence loss are different.** Immutable `hindsight_source_evidence`, unit evidence and exact object bindings survive ordinary raw cache rebuild (`packages/core/src/db/hindsight-source-evidence-repo.ts:52-65`, `:88-124`); D78 capture/import/verification evidence is also separate from raw staging. Losing all such evidence is the provider-only recovery case D77 still does not implement.
6. **New native observations have no existing Local unit binding.** Their native content, sources and lifecycle can be synchronized, but Canonical records also require Taki policy and trusted provenance. No producer may manufacture importance, visibility, retention, original timeline spans or an imported source-unit association just to make `CanonicalMemoryRecordSchema` pass. The explicit prohibition is `.trellis/spec/backend/memory-current-state-cutover.md:109-111`.

### 9. Provider application-state extension: concrete reusable hooks

An independent versioned application-state contract is justified by the omitted Taki bodies and closed native logical-object set. This is a **proposed engineering boundary**, not an existing endpoint. It should persist Taki source/provenance artifacts, policy revisions, Block documents and their exact native associations, without introducing a second mutable copy of native semantic facts. The following existing seams are sufficient starting points; they do not justify an extension that merely patches private methods and calls itself upgrade-safe.
