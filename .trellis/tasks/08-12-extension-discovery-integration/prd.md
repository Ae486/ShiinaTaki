# Converged Extension Discovery and Integration

## Goal

Prove that Host control, governance, Approval, credentials, MCP, and Skills compose into one bounded, truthful extension
surface across Core, Nodes, Agent discovery, and Home.

## Dependencies

- All preceding production children complete their proportional checks.

## Scope

- Registry collision rejection and host-qualified progressive discovery/search/describe/call bridge when scale requires.
- Immutable per-Run Host/extension snapshot and truthful tool-result ownership labels.
- Restart/reconnect/upgrade/migration convergence across Core, Host, Agent, and Home.
- Mandatory real-process two-Node Host-control harness: both Hosts advertise the same capability; explicit routing,
  reconnect generation replacement, cross-Host isolation, and interrupted read/side-effect settlement are exercised.
- Source/role security sweeps, privacy/cache sweeps, final stack fixtures, docs/spec/ADR/HANDOFF updates.
- Owner manual acceptance matrix.

## Acceptance Criteria

- [x] Agent sees only currently eligible host-qualified extensions and cannot infer a Host from label/path.
- [x] Core/Home/Host state converges after enable/disable/reload/reconnect/restart without silent replay/fallback.
- [x] A real simultaneous two-Node harness proves explicit same-capability routing, generation-safe reconnect,
      cross-Host disconnect isolation, and distinct cancelled versus `outcome_unknown` interruption results.
- [x] Skills cannot grant permission and Agent tools cannot mutate governance, credentials, trust, or CRUD authority.
- [ ] Full relevant automated gates and owner-observed manual checks pass.

## Out of Scope

- Autonomous Run, Run Receipt, Scheduled Task, Heartbeat, Experience Review, or Learning Proposal activation.
