The temporary launcher passed `cargo build --offline --features custom-protocol`; the five Node
helpers passed `node --check`; `node run-qa.mjs` passed 12/12 groups; `node verify-assets.mjs` passed
snapshot, served-asset and CSP checks. Existing product package gates are recorded in the linked G4
implementation evidence and were not rerun by this helper.

fixture omitted timing settings, producing three expected warnings that the frontend retained its

driver issues (Enter character events, intentional ellipsis classification and the frozen G4
permission title) were corrected; the first run is retained as `qa-instrumentation-first-run.json`.

Inputs were CDP mouse, wheel and keyboard events, with CSS viewport emulation in a hidden native
WebView2 host. They do not replace manual OS window/focus/resize checks. Copy validation covered
available controls and selectable text; the system clipboard was not read or written. No real DB,
Keyring, external provider, Core authority or Host capability was exercised. Owner visual acceptance
remains pending and must be recorded separately.
