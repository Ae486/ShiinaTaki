## Scope

- Accepted Perception envelopes retaining nullable idle, real dispatch Host identity/generations and a separate consent/observation epoch.
- Core authenticated source leases and aggregate presence, with independent window/socket lifecycles and bounded reports.
- Desktop own-interaction/visibility and committed-message exposure producers; no extra sensor acquisition.

- User Timezone settings/designated-device producer over child 1's existing authority.

## Acceptance criteria

- [ ] **C2-01** Null idle, sensitive/refused source, pause during await, Host replacement and resume with stale cached samples never prove fresh presence.
- [ ] **C2-02** Home/Chat/Pet independence, replayed sequence, future/stale report age and retired generation remain correct.
- [ ] **C2-03** Phone-shaped explicit input may establish presence while Desktop capability availability remains false; cross-device display association is not invented.
- [ ] **C2-04** Actual message exposure and same-device presence produce bounded union intervals; duplicate/overlapping reports count once and unknown gaps count nothing.
- [ ] **C2-05** A historical message view after the feedback deadline cannot reopen a settled observation.
- [ ] **C2-06** Native minimize/focus/render/visibility behavior, reader position and Pet presentation are verified without manufacturing an ACK.
- [ ] **C2-07** Timezone fixed/follow modes, source retirement and future recomputation work through the existing authority.
