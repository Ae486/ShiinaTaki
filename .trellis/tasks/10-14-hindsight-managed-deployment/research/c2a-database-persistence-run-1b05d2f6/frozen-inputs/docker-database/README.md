[database design](../c2a-database-design-review.md) has SHA-256

The payload reads `pg0-embedded` and `psycopg2-binary` distribution metadata, hashes metadata
and package-listed pg0 assets, and returns numbered relevant Python source lines. It records
effective UID access and ancestor traversal, HOME, the fixed data seed's metadata and at most
32 immediate entries (no contents or recursive walk). It does not import pg0, either SQL
client, `hindsight_api`, dotenv or providers. Windows pg0 0.15.0 is only a research lead;
the reported versions and source come from the pinned Linux image.

Only existing, readable, executable package-listed ELF files named `postgres`, `initdb`,
`pg_ctl` or `pg_controldata` may run, once per name with exactly `--version`. Child environment
is exactly HOME=/home/hindsight, LANG=C, LC_ALL=C; stdin is closed, cwd is `/`, and output is
combined and bounded to 4 KiB per command. No PATH lookup, pg0 command, initialization,
extraction, download, storage write or cache/model scan occurs. Version execution establishes
loader success only for that utility and environment; it does not inventory every library.

The script has a 50-second alarm, three seconds per utility plus at most one second to reap,
32 assets, 64 KiB per source, 24 KiB per source excerpt, 512 MiB per hashed asset and 768 MiB
total streamed hashing. Package inventory is limited to 4,096 entries / 256 KiB path text;
metadata files are limited to 256 KiB. JSON including newline is at most 128 KiB. A limit
produces an unresolved result; exceeding the final output limit replaces partial evidence with
an explicit incomplete record. Root must also bound total probe create/start/attach time to
60 seconds and returned stdout to 128 KiB; retain at most 8 KiB of Docker stderr separately.

### Runtime and evidence contract

The actual Permission Gate/Host admits two independent private fake submissions. The relay holds
only the first matching inject execute, observes no database, and releases the unchanged frame
within ten seconds of capture. Its separate timer closes the relay on failure; the original
90-second authority is unchanged. No authorization or private frame is exported.

The fixed child preserves independent fake/dotenv validation and the five-second wrapper marker.
It imports the existing `enable_linux_reaping()`, clears fake environment/references, and uses
allowlisted DB environments. First generation runs pg0 once, verifies the accepted tools, creates
one logged table and commits one deterministic 4 KiB row using explicit async SQL BEGIN/COMMIT;
a new connection verifies it. Second generation only starts raw postgres on the same cluster and
SELECTs that original row. The same source hash, tool hashes, cluster and original manifest bind it.

SQL/data verification has one 60-second startup deadline. TERM after readiness is normal stop;
initialization interruption, premature process exit and lifetime expiry remain failures. Each
wrapper is finite at 300 seconds and reserves its last 25 seconds for stop. Raw pg_ctl fast stop,
direct/adopted wait/reap, clean pg_controldata, full stopped-volume scan and final report share
25 seconds from first TERM. The last half second is reserved within that bound for report
publication, including a failed/incomplete result; it does not extend the deadline.

The complete scan streams <=1 GiB / 4,096 entries, with 1 MiB chunks and 72-byte overlap. Only
contained installation file links to scanned regular targets are allowed. The stopped marker
precedes the scan; `last-stop.json` is the only file published afterward and Root scans its actual
returned bytes. Native group supervision remains 30 seconds; Docker stop grace is 45 seconds with
a separate <=55-second client deadline. No standalone memory/CPU/PID quota is claimed for the adapter.

It returns `last_stop_raw` as the original UTF-8 text plus its SHA-256. The launcher writes and
rereads `S/first-stop.json` before resume can overwrite the in-volume report. Final stopped-container
`docker cp` reads only `/home/hindsight/.pg0/c2a-db/last-stop.json` to `S/final-stop.json`, bounded
to ten seconds and validated as a regular <=128 KiB file. No inspector or extra restart is used.

identities, actual bounded Docker outputs/events and no-TTY exec facts, scans and failures.
