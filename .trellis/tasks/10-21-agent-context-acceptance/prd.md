# Agent context end-to-end acceptance

## Goal

Verify the integrated SDK, delegation and source-context changes against the original Co-Watching failure and the settled runtime/product behavior.

## Requirements

- Own cross-child acceptance against parent AC01-AC11; do not duplicate child implementation ownership.
- Combine deterministic pipeline/lifecycle tests, actual model-input inspection, authorized semantic model trials and user-facing owner trials.
- Verify ordinary self-report and unrelated conversation alongside the original source-confusion case.
- Preserve current playback, foreground, revision, cancellation, delivery and memory-authority invariants.
- Distinguish historical evidence, current automated results, live-model observations and owner acceptance.

## Acceptance criteria

- [ ] All preceding child evidence is linked with exact code/dependency/config baseline.
- [ ] End-to-end external source -> child -> result/publication -> replay -> compaction retains known origins.
- [ ] Semantic evaluation covers external/self/mixed sources and later follow-up, with actual outputs and explicit failures.
- [ ] Parent stop, independent child stop/continue, record-only completion and later parent continuation meet G1-G4 without duplicate effects/speech.
- [ ] Task/role instructions and actual allowed/excluded tool selection compose correctly, including explicit empty selections. Child Memory reads work while mutation attempts and automatic private-work ingestion remain unavailable; the main Companion retains its permitted Memory operations.
- [ ] Revision/source retirement, foreground chat and playback delivery controls pass on the integrated implementation.
- [ ] Restart/unknown-effect and memory-provider limitations are accurately reported.
- [ ] Child conversation UI is validated, and pending owner trials remain pending until confirmed.
- [ ] No previous manual playback issue or historical acceptance is silently marked passed.

## Dependencies and constraints

Production acceptance execution follows the upgrade, delegation and source-context children plus their targeted checks. Fixtures/scenarios and supported model connectivity may be prepared earlier. Follow [parent requirements](../10-21-agent-delegation-source-context/prd.md). The owner explicitly authorized real-model E2E testing on 2026-10-22, including required bounded model calls using isolated test-owned state. Production deployment and real-user memory mutation remain outside scope.

## Definition of done

The parent receives a complete evidence matrix identifying pass/fail/unverified per criterion and any owner-confirmed outcome. Research or fixture success cannot substitute for actual model or human acceptance.
