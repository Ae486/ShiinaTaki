The colocated real-prepared-playback test is explicitly opt-in. It combines a real model, existing Workspace tools,
a hash-pinned native result and actual browser observations with controlled acceptance/snapshot/transport fixtures;
it does not establish production startup, personal acceptance or final desktop delivery. The separate runtime tests
exercise the production composition with synthetic model/native/browser ports and real execution/delivery owners.
Permission regressions additionally retain production Run capture, MCP manager, Governance and Approval services;
their inert transport counts actual dispatches before allowing downstream preparation.

Explicit URL analysis accepts only native-supported direct Bilibili video URLs, preserves the exact probed part and
reuses the same catalog/native progression without creating a viewing session. Pending native work holds its existing
internal Run and releases the Character lane. One ordinary Agent final reply becomes one generic prepared Class A
publication; the root remains current until the child commits. Native probing/status/submission may yield to primary
chat and reconcile the original key, while the bounded final Agent reply completes without automatic regeneration.
Cancellation stops this accepted purpose and its pending output, without claiming cancellation of the upstream job.
