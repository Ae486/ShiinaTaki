# Source-preserving context and prompts

## Goal

Preserve useful known source information through delegated work, publication, replay, compaction and relevant memory processing, so external content is not mistaken for the user's own experience.

## Requirements

- Inherit CS01-CS11 and parent R09-R12, AC06-AC09. Native role/tool associations remain intact.
- Use optional material-level known facts/references. Separate generation origin from material source and never invent missing attribution.
- Cover direct/background generation, child input/results, published speech, replay/compaction and memory admission/extraction/maintenance/use within current eligibility.
- Research current official documented and implemented practices as needed before prompt/format changes. Verify the actual consuming input rather than relying on visual tags alone.
- Preserve foreground/source/revision/playback gates and current memory authority.
- Keep genuine user self-reports distinguishable from quotations, external first-person material and mixed-source conversation.

## Acceptance criteria

- [ ] A boundary matrix records known source facts and their retention/projection through every relevant consumer.
- [ ] Actual serialized model requests retain the intended roles, tool associations and available source distinctions.
- [ ] Publication/replay/compaction preserve necessary attribution independently of private transcripts and transient task files.
- [ ] Missing/legacy information stays unknown; current unrelated conversation is not forced into a global Co-Watching mode.
- [ ] Representative before/after semantic cases cover external material, explicit self-report, mixed/quoted content, delegated follow-up, correction and post-compaction use.
- [ ] Memory stages are source-aware without ingesting previously ineligible raw material or claiming control of uninspected provider-owned prompts.
- [ ] Official evidence, deterministic checks, live-model results and owner acceptance are reported separately.

## Dependencies and constraints

The SDK upgrade supplies the implementation baseline. Runtime/result and source/persistence shapes are reviewed jointly with the delegation child. Follow [parent requirements](../10-21-agent-delegation-source-context/prd.md). XML/JSON/Markdown and field names remain unselected until evidence supports a concrete representation. No sentence-level provenance, new classifier Agent, full provenance graph, retrospective source invention or live memory rewrite is included.

## Definition of done

Source plumbing and prompt changes have traceable evidence at real consumer boundaries and the specified semantic cases. An initial wrapper alone cannot satisfy the task.
