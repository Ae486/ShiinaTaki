## Decision verdicts

- (a) `source_blocked` -> `completed` with `result.outcome=source_blocked`, run stays open: **confirmed**. Shared `superRefine` only forbids reason/errorCode on `completed`; the command (snapshot + inventory + conversion) genuinely finished and the blocked state lives in the run, which the card renders from `status.run.progress.phase === "blocked"` ("有来源需要处理") with resume/replace/exclude offered. Not a failure of the producer.
- (b) `binding_unavailable` -> `failed`/`runtime_unavailable`/`MEMORY_RUNTIME_UNAVAILABLE` with result carried: **confirmed**. Card shows Canonical Local authority + unavailable runtime + `recoverBinding`; receipt stays single; schema permits result on failed.
- (c) Hindsight-mode turns open an unassigned header-only group per turn: **confirmed, bounded**. `currentLocalCandidate` returns null under Hindsight, so `assigned_epoch_id` is null, `finalize` closes the header only (no witness write), and `assignPrimaryCandidate` never adopts finalized unassigned groups. Members are exact rows only (no bodies); growth is one header + N member rows per turn, same order as the Timeline itself. Hindsight `onPrimaryCommitted` path untouched (`recordPrimaryCommitted` still goes to the Hindsight subsystem). Acceptable; a retention sweep for closed headers is a later hardening, not an S2a defect.
- (d) `runtime.available` is `true` under Legacy/Hindsight: **confirmed as the only truthful reading** — the Local binding is not the selected runtime there, so "unavailable" would be false; `memory.authority.status` keeps its own Hindsight availability. The card labels the authority separately, so no usability is implied.
- (e) `.resume(` sweep workaround: **replaced** with the rename (finding 2).
