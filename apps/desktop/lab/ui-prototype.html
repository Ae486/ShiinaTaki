🎯 优化原理解析

1. 悬浮 Toast (最推荐)

将操作反馈从普通流中抽出，使用 fixed top-4 浮在页面上方。不仅不占位置，而且无论在哪个页面操作，反馈都在同一位置，符合用户直觉。

2. 预留槽位 (用于表单报错)

给输入框下方固定留出 min-h-[1.25rem] 高度。平时透明，报错时只改变 opacity，排版永远纹丝不动。

3. CSS Grid 0fr 展开

传统 JS 算高度在折叠时容易抖动，而现代 CSS 采用 grid-template-rows: 0fr -> 1fr 能自动处理自适应内容，且享受 GPU 丝滑加速。

设计规范与控件陈列室

包含基础按钮完整 5 态、像素级垂直居中对齐公式、以及加载骨架屏标准。

1. 按钮交互 5 态完整性规范

任何可点击的元素都必须具备：默认态、Hover 悬浮、Active 按压微弹、Focus 聚焦环、Disabled 禁用态。

2. 像素级垂直居中公式

❌ 容易失准的写法：

漏了 items-center，图标默认 stretch 或者顶边对齐，文字因为不同字号 line-height 导致视觉重心下沉。

✅ 推荐的黄金组合：

flex items-center gap-2 + 图标加 shrink-0 + 文字加 leading-none 统一基准。

3. 骨架屏 (Skeleton) 规范

在数据还未到达前，使用尺寸与真实内容一致的发光骨架，避免数据加载瞬间“啪”地闪现。
