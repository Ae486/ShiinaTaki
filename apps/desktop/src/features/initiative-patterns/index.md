# features/initiative-patterns/

Disposable Home/Chat Pattern authoring and same-Monitor policy projections over Core authority.
All internal identities remain transport/callback bindings; no local persistence or mutation replay.

- pattern-state.ts — Shared-derived client boundary and coherent list/detail/history state
- pattern-controller.ts — event-driven last-good reads, selection staging and serialized CAS-bound commands
- use-patterns.ts — current Home client and effective page-visibility binding
- pattern-labels.ts — closed Chinese lifecycle/source/refusal/condition labels and date formatting
- pattern-definition-view.tsx — complete purpose/conditions/context/outcome/timing/lifetime review and semantic differences
- pattern-candidate-card.tsx — compact proposal and locally frozen exact-review lifetime
- pattern-review.tsx — distinct domain confirmation dialog with explicit stale-review replacement
- pattern-draft.ts — editable proposal defaults, finite atom constructors and local/absolute time conversion
- use-pattern-editor.ts — retained draft/base identity, validation and unchanged-current-submit settlement
- pattern-editor.tsx — manual proposal editing with deliberate conflict acknowledgement
- pattern-condition-editor.tsx — closed supported atoms and label-only completion selection
- pattern-options-editor.tsx — context/outcome, cooldown/chance and validity controls
- pattern-history.tsx — immutable accepted/candidate history and rollback-as-new-proposal action
- pattern-lifecycle.tsx — pause/resume and explicitly confirmed retirement
- pattern-tool-display.ts — allow-listed historical authoring-tool results with no binding metadata
- follow-up-tool-display.ts — finite follow-up outcome/window disclosure, preserving canonical payloads and excluding raw bindings/errors
- chat-pattern-candidates.tsx — actual Chat proposal adjunct within its existing scroll owner
- initiative-setup-controller.ts — guarded setup/config reads and explicit standard Skill/seed/toggle actions
- use-initiative-setup.ts — setup connection/visibility adapter and existing-page navigation
- initiative-setup-card.tsx — effective policy, source readiness, Skill import and example proposal controls
- initiative-policy-view.tsx — truthful global limits, periodic/event control scope, units, target and User Timezone disclosure
- initiative-policy-controller.ts — existing Monitor policy read owner, hidden gaps and old-client fencing
- use-initiative-policy.ts — Monitor mode/visibility/current-client hook
- initiative-policy-diagnostics.tsx — bounded pre-admission reason/counter disclosure and backoff controls inside the existing Monitor
- initiative-backoff-controller.ts — retained backoff reads, hidden gaps, serialized explicit reset and old-client outcome fencing
- use-initiative-backoff.ts — Monitor availability/current-client binding without cancelling hidden mutations
- initiative-backoff-view.tsx — truthful frequency stage/counts/wait time and explicit reset with independent refresh errors
- initiative-wake-labels.ts — Chinese producer-reason and source labels
- pattern-test-fixtures.ts — isolated deterministic projections/client support, outside the production import graph
