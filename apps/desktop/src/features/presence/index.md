# presence/

Disposable Desktop evidence producers. Core owns identity validation, leases, interval union and feedback disposition.

- surface-presence.ts — one sequenced source, bounded original input age and explicit listener continuity, local text-region union and terminal retirement
- surface-presence-lifetime.ts — physical-client source ownership across StrictMode and render detach/remount
- use-surface-presence.ts — actual listener attach/detach proof, own-window observers and bounded source renewal at Home/Chat/Pet lifecycles
- own-window-visibility.ts — fail-closed display withdrawal before every query, with routine checks distinguished from actual hidden/blur source interruption
- text-exposure.ts — actual nonempty text intersection for two continuous seconds; no scroll or focus side effects
- use-committed-exposure.ts — rendered text observer ownership with stable committed coordinates and region cleanup
- committed-exposure-context.ts — current surface owner supplied to actual Chat Markdown/Pet text renderers
- user-timezone-controller.ts — Home-only designated reporter, Core read model, explicit CAS settings and stale-result fencing
- use-home-timezone.ts — physical Home generation and device-zone visibility/focus revalidation
