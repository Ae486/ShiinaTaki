# lib/icons/
Self-drawn inline-SVG glyphs (our own artwork — no icon package, no imported asset file). One glyph per file so the
owner's hand-drawn replacements land file by file; the page and wheel registries carry the icon as a component slot.
- glyph.tsx — the shared 24x24 stroke-svg frame + IconProps / IconComponent (the registries' slot type)
- chat-icon.tsx — speech bubble (chat page / wheel row)
- settings-icon.tsx — hub with eight teeth (knobs page / wheel row)
- costume-icon.tsx — clothes hanger (costume page / wheel row)
- home-icon.tsx — house (the wheel's "open home" row)
- operations-icon.tsx — stacked layers (memory + storage maintenance page)
- perception-icon.tsx — eye (perception + privacy page)
- mcp-icon.tsx — a plug and cord (the MCP lifecycle page)
- skill-icon.tsx — an instruction sheet and spark (the Skill lifecycle page)
- tool-icon.tsx — open-end wrench (the chat tool-activity card)
