# Devlog — 开发汇报档案

> 面向项目所有者的审查通道，简体中文（工程文档仍为英文——本目录是汇报，不是设计文档）。
> 由开发主脑（Claude）在全权推进期间维护。

## 文件说明

| 文件 | 内容 | 更新时机 |
| --- | --- | --- |
| `m1.md` … `m5.md` | 每里程碑一份：逐 issue 一屏摘要 + 里程碑收官详报 | 每个 issue 验收后追加；里程碑收官时补详报 |
| `manual-checks.md` | 排队中的人工验收清单（需要你的眼睛/双手的项目），复选框格式 | 产生人工验收项的 issue 完成时追加；你验完可打勾 |
| `blocked.md` | **仅在触发"停止协议"时存在**：无法解决的问题 / 需要你拍板的需求 | 出现即写、即停；你处理后我删除该条目 |

## 约定

- 推送节奏：每个里程碑收官后 push 到 origin/main（连带触发双平台 CI）。
- issue 关闭：验收通过后由主脑关闭并附验收证据评论——GitHub issue 状态即进度真相。
- 遇阻即停：绝不盲目开发；`blocked.md` 非空时后续受影响 issue 不会启动。
