## #14 — 宠物悬浮窗（2026-07-13）

**结论：透明无边框置顶悬浮窗落地，含渲染节流 governor + 状态机 + 拖拽持久化。** 门禁全绿（desktop typecheck / lint / 11 前端测试 / -r typecheck / cargo build），check 零缺陷。

**做了什么**：
- 新 `pet` 窗口（透明/无边框/`shadow:false`/置顶/跳过任务栏/不可缩放/不抢焦点/首帧后显示），独立 `pet.html` 入口 + `capabilities/pet.json`。
- 框架无关渲染器（`renderer/`，**零 React 导入**）：`stage.ts`（透明 PixiJS app，governor 拥有 ticker）、`render-governor.ts`（渲染节流：满帧/失焦 15fps/待机 30fps/隐藏时 stop）、`state-machine.ts`（纯 idle/thinking/working/sleeping FSM）、`pet-scene.ts`（装配）、`live2d/`（加载 taki 模型 + 显式绑定 governed ticker + eyeBlink + 循环 idle 动作，修 spike 时眨眼不跑的问题）。React↔Pixi 唯一桥 `pet-stage.tsx`。
- 拖拽：`startDragging()` + 4px 死区（轻点走 #16 点击通路）；位置持久化 `tauri-plugin-window-state`（POSITION-only、仅 pet 窗、**纯 Rust 侧不过 WS**——几何属本地窗管，不入 Core）。

**用户决策落地**：位置持久化=1a（官方插件）；渲染节流=2a 可配（`renderThrottling` 默认 on，"被遮挡暂停"明确 out-of-scope，接口测不到）；术语=渲染节流；置顶=默认属性。

**登记的延期/取向**：D19（节流开关配置化→M5 #24）、D20（main+pet 双窗口启动取向→M5 #22 或用户提前裁定）、D18 澄清为发布工程 track（专有运行时不进 bundle + dev-gate spike，v1 打包前做）。DWM 抑制未加——先只用 `shadow:false`，真机若见残留 Win11 边框再补（方案已备）。

**待人工验收**（manual-checks #33-39）：透明合成、无 Win11 边框、可见眨眼呼吸、拖拽手感+死区、位置持久化、不抢焦点/无白闪、governor 待机 CPU vs #13 的 ≈89% 基线。

**质量流程**：research（Tauri 窗口 API 6 主题验证，含位置持久化决策材料）→ 用户裁定 1a+2a → implement（Opus）→ 主脑亲验（移除未用 JS 依赖、复跑门禁）→ check（Opus，零缺陷）→ 自主提交。
