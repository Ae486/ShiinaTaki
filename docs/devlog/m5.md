### 记忆重设计定稿(依据 hermes-memory-analysis)

六件套:**A1** 注入加固(围栏+来源标注+流式洗涤+写入威胁扫描;**最小版提前随 T3** — 采样内容进提示词第一天就有围栏)、**A2** 写入语境标签(primary|heartbeat|flush|subagent,非真实对话回合不得沉淀;**T4 心跳第一天带上**)、**A3** 有界自整合(layer softBudget+压力触发+每夜 croner)、**D1** 统一 MemorySource 接缝(~6 钩子;D9 情绪胶囊从静态字符串变 companion-state source;v2 向量/MCP 归档=注册一个 source)、**D4** 本地用户模型层(取 Honcho dialectic 概念、拒其 SaaS 依赖)、**D3** 召回命中计数(异步,排名学"哪些记忆真被用上")。

**一条记忆一个 md 保持**:每条 frontmatter 元数据是功能地基(importance/mood-gate/过期/ownership)、坏写爆炸半径有界(对照 Hermes 大文件整体覆盖事故)、检索走可重建 FTS5 索引不扫文件;数量上界由 A3 整合兜住("一条记忆一个文件"≠"一个原始事件一个文件到永远")。角色记忆 vs 整体记忆=layer 的 ownership 策略字段,已是一等公民。

保留不动:layer-registry(加层=一行)、files-are-truth、pinned 永不截断、disclosure gate、intentions/mood-gating、per-Character ownership、v2 向量混合计划。明确拒绝:外部记忆服务依赖、HRR/知识图谱、会话冻结快照(陪伴新鲜度>缓存)、二级模型摘要召回。

### 主动性架构(依据 m5-proactivity-survey)

三层机制+供给+出口:**反射层 Hook**(零 LLM 零成本)/**时钟层 Cron**(croner,精确时刻,有记录,定时 agent 回合为一等载荷)/**意识层 Heartbeat**(近似节拍,LLM 判断,静默默认)。分工判据(OpenClaw 决策表):精确/隔离→cron;情境/近似→heartbeat;纯反应→hook。**用户明确要求的提醒走 cron,agent 自己惦记的走 commitments**(骑 heartbeat 浮现)。心跳成本工程:空拍跳过、清单行带沉默条件、轻上下文/可配小模型门;运行与投递解耦、忙时让路;全部受频控/安静时段/Privacy Pause 约束(反模式:含糊清单行必刷屏、满上下文心跳≈100K token/拍)。

### 自定义与社区化三原则(2026-07-18 追加拷问定稿)

1. **面板权威,双入口一存储**:可视设置面板是唯一权威管理面;对话中 agent 调配置接口写**同一份存储**,面板必然可见可改可删。任何 agent 可写配置,面板必有对应可视条目。
2. **习惯产物分级**:agent 自习惯的产物=**结构化配置行**(cron 条目/带 {schedule, condition, prompt, 沉默条件} 的清单项),触发层永远是确定性引擎代码(croner 节拍/到期门控/activity 条件预判由代码判定,零 token),LLM 只管判断与措辞。用户发起的对话式造 skill(内置 skill-develop skill)随 #25;**agent 自主写可执行代码(skill/hook 文件)延期 = D36**。
3. **进口皆不可信**:社区导入走信任分级(builtin/official/community)+威胁扫描(复用 A1 扫描器)+来源展示;skill 永不能自我授权(同一 Permission Gate 之下,Gate 不关心提示词谁写的);MCP 保持操作员配置(ADR 0006);对话内安装必弹确认。格式对齐 agentskills.io(深度兼容延期 = D37)。

红线:**自然语言授权=既有 Approval 流程,零新机制**——对话表意→能力请求→Gate 弹标准 Approval(once/session/always)→授权入 #23 权限面板可见可撤。已归属模块的东西不再单拎大做文章。
