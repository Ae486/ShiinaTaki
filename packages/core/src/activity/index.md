# core/activity/
- activity-layer.ts — composition point + home of the deterministic defaults (poll/pulsetime/dwell/idle/span/cap/backoff, with ACTIVITY_POLL_MS exported so a sibling sampler can express freshness in ticks); createActivityLayer(deps) → { state, sampler }; the privacy predicates are forwarded verbatim from core/perception, never owned here
- activity-state.ts — OS-neutral bounded rolling window of foreground samples; heartbeat-merge coalescing + dwell + idle marking + span/entry-cap bounds; seal() ends the live stretch carrying no data at all (current() → undefined, next push opens a fresh entry), the one signal a caller that must disclose nothing can still send; pure/deterministic (injected clock, no OS deps); T4 reads entries()/current()
- activity-sampler.ts — SYSTEM-initiated 30s poll loop (setInterval.unref()): skips routing entirely while Privacy Pause is active or no node connects (quiet once-per-streak), else route foreground-window → safeParse → for a sensitive app drop the whole sample AND seal the state (so no sibling sampler keeps acting on the last non-sensitive foreground) → scrub the title → state.push; NO_NODE quiet-skip, DENIED stops the session, other errors exponential-backoff; never throws; running() reports whether it is still scheduled (the card's sampling badge)
- render-activity.ts — read-side renderer: reportable entries → compact English activity block, wrapped whole in the A1 untrusted fence; "" when nothing reportable
