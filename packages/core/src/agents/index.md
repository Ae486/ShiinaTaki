# core/agents/
- chat-agent.ts — AI SDK v7 streaming chat loop (model + store + memory + optional autoMemory/visionModel/attachments/imageMemory/extraTools/characterTools/instructionsExtra/approval); per turn prepends the base prompt + assembles memory context + skills list + avatar vocabulary + binds memory/skills/MCP tools plus per-character avatar tools behind the toolApproval gate; image turns route to the vision slot (in-flight FilePart tail swap) and fire the detached image-description hook; yields text deltas, persists the FULL turn (tool-calls + results + text), abort-aware partial-text persist, fires auto-writes detached; a cancel before any output retracts the user row (deletes it + skips the memory writes) via TurnContext.onRetract
- base-prompt.ts — BASE_SYSTEM_PROMPT: the stable identity + tool-use + "never claim a tool ran without a tool-result" truthfulness floor (anti-hallucination), prepended before memory context
- conversation-store.ts — SQLite-backed conversation store (repo + onAppend/onRemove injected); exports REPLAY_WINDOW; appendUser(+image parts, returns the entry)/appendAssistant/appendTurn (full-turn fidelity) + removeEntry (cancel-retract); replays the window as multi-part ModelMessages (image parts project to text — bytes never replay)
- turn-mapping.ts — maps AI SDK response messages <-> TimelineEntry (tool-call/result + image parts persist; image replays as text projection); + toUserEntryInput; conversation-store's only consumer
- turn-queue.ts — per-characterId async mutex serializing turns (append user -> stream -> append turn commits before the next send); concurrent across characters
- turn-registry.ts — per-character AbortController registry (begin/end/cancel); the cancellation seam shared by chat.send + chat.cancel
