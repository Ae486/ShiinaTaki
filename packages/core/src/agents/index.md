# core/agents/
- chat-agent.ts — AI SDK v7 streaming chat loop (model + store + memory + optional autoMemory/visionModel/attachments/imageMemory/extraTools/characterTools/instructionsExtra/volatileContext/costumeChanged/approval/onUsage/onOverflow); per turn composes DAY-STABLE instructions (base prompt + day-date line + assembled memory context + skills list + avatar vocabulary) and appends the volatile `<turn-context>` tail (current-time line + wired volatile context, Q4/ADR 0008) onto the outgoing user message — in-flight only, never persisted, the third additive seam beside the FilePart swap and the costume notice; binds memory/skills/MCP tools plus per-character avatar tools behind the toolApproval gate; image turns route to the vision slot (in-flight FilePart tail swap) and fire the detached image-description hook; a costume swap prefixes a one-shot COSTUME_CHANGE_NOTICE onto the model-facing user message (1f, never persisted); yields text deltas, persists the FULL turn (tool-calls + results + text), abort-aware partial-text persist, fires auto-writes + the batch-6 usage report (provider usage + estimate-at-send) detached on committed turns only; a classified context-overflow on a side-effect-free first attempt recalibrates via onOverflow and retries ONCE under the shrunken window (R2 — never compaction); a cancel before any output retracts the user row (deletes it + skips the memory writes) via TurnContext.onRetract
- base-prompt.ts — BASE_SYSTEM_PROMPT: the stable identity + tool-use + "never claim a tool ran without a tool-result" truthfulness floor (anti-hallucination) + the memory floors (T5-R12/R16-R19: never answer the user's past from impression, OpenClaw-shaped search triggers, one-search + say-you-checked fallback, pin-on-repeat, fix-on-read, supersede-don't-append, deliberate experience writes, card-wins last) + the injected-context contracts a user must not be able to edit away (what an `<untrusted-observation>` block is / trust only these exact tags, what the `<turn-context>` tail is and where the two time lines arrive, what a `<conversation-summary>` head is — her own earlier record, never recited, memory store wins on disagreement — batch 7, anti-recitation); prepended before memory context — behavior norms for the same surfaces live in prompt/system/assistant-layer.md
- compaction-pass.ts — createCompactionPass({view, timeline, summaries, autoState, flush, slot, config, logger}) -> { maybeRun }: T5-R5's background compactor riding auto-memory's chain LAST — trigger = view estimate > triggerRatio × the history wall; retires all but the newest keepMessages rows; flush-before-retire (watermark-guarded, monotonicity asserted); ONE generateText on the utility slot over [old summary + rendered retiring span] with the amended Part D prompt (R10 voice whole-constant); upsert VERBATIM only on full success (no length cut anywhere — owner ruling); counts-only pino
- context-window.ts — selectWindow(entries, budgetTokens, maxMessages): pure token cut (newest kept, oversized-single kept, maxMessages hard backstop, leading-tool-drop) -> { entries, windowStartSeq, estimatedTokens }; THE one window boundary history() and the flush share (batch 6)
- conversation-store.ts — SQLite-backed conversation store (repo + onAppend/onRemove + optional window budget + optional SummaryReader + optional onWallHit); exports REPLAY_WINDOW (the R1 message-count hard backstop); appendUser(+image parts, returns the entry)/appendAssistant/appendTurn (full-turn fidelity) + removeEntry (cancel-retract) + windowStart (the flush-coupled boundary, summary-substitution aware) + estimatedTokens (the compaction trigger's input); replays the Replay View (ADR 0008: summary head substitution → R4 folds → emergency cut, wall-hit warn deduped per boundary) as multi-part ModelMessages (image parts project to text — bytes never replay)
- overflow-error.ts — R2's pure overflow classifier: isContextOverflowError (APICallError + 4xx/absent status + sourced context-length phrase family; unrecognized fails open — no retry) + observedTokensOf (the failing request's provider-reported token count, never the advertised maximum)
- replay-folds.ts — foldUnderPressure(entries, budget) -> { entries, estimatedTokens }: T5-R4's pure under-pressure folds inside the replay view (ADR 0008 idempotent projection; copies only, stored rows untouched) — stage a snapshot-class results (Q5 capturedAt marker) beyond the newest 3 per toolName, stage b fact-class results oldest-first, stage c tool-call args over the ~200-char floor; Hermes-style one-line traces; under budget = zero folds
- turn-mapping.ts — maps AI SDK response messages <-> TimelineEntry (tool-call/result + image parts persist; image replays as text projection); + toUserEntryInput; conversation-store's only consumer
- turn-queue.ts — per-characterId async mutex serializing turns (append user -> stream -> append turn commits before the next send); concurrent across characters
- turn-registry.ts — per-character AbortController registry (begin/end/cancel); the cancellation seam shared by chat.send + chat.cancel
- untrusted-fence.ts — the A1 minimal fence: fenceUntrusted({source,content}) → XML-delimited `<untrusted-observation>` block labeling content DATA-never-INSTRUCTIONS; neutralizes any literal closing tag so hostile content can't escape; reused by every untrusted-content producer (T3a activity, later T3b/screenshot/T5)
- window-calibrator.ts — createWindowCalibrator({repo, slot, declared}): R1 tier-2 EMA correction factor over the estimator (clamped) + R2 overflow shrink (floor(observed×0.9), never above declared), persisted via window-state-repo; a lowered declaration is written back so runtime and operator status agree while an earlier overflow shrink survives; effectiveWindow() returns the estimator-unit budget
