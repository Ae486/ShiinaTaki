# core/initiative/

- initiative-runtime.ts — trusted opportunity admission, execution-bound captured tools for pre-Agent evidence, selected-context fences, first-model quota charging and structural decisions
- initiative-presentation.ts — captures dynamic Avatar vocabulary/generation and executes staged presentation through the original governed Attempt
- initiative-composition.ts — wires shared policy, User Timezone, delivery and Scheduled final-result consumption; exposes the same delivery owners to explicit Co-Watching and remains inert without an eligible caller
- presence-composition.ts — connects accepted evidence, independent operator sources, durable reply reconciliation and bounded feedback maintenance without waking a model
- wake/ — deterministic supported-condition matching, bounded candidate selection and policy adapter over the shared runtime
- initiative-context-builder.ts — deadline/cancellation-bound selected Memory and frozen observations, actual source manifests, outcome constraints and common User Timezone rendering
- patterns/ — sole immutable Pattern/review/source/CAS authority, command idempotency and readable revisions
- pattern-composition.ts — actual config, Pattern/Intention/viewing sources, Memory and Run composition; explicit startup and scoped cancellation
- manage-pattern-tool.ts — primary-only source-bound authoring/management with bounded paging and no confirmation authority
- authoring-skill.ts — fixed bundled bytes through standard immutable Skill import, preserving user packages and disablement
- initiative-setup.ts — current settings/source projection and explicit reviewable seed proposals
- intentions/ — source-bound finite automatic follow-up plans, exact canonical Run claims and terminal deduplication
- backoff/ — qualified-feedback 1x/2x/4x/daily eligibility over canonical admissions and real engagement resets
- plan-follow-up-tool.ts — primary-only automatic finite planning from the actual user source; no confirmation card or Schedule conversion
