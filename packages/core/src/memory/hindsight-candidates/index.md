# hindsight-candidates

Experimental D1-A source contracts. No Memory Operation, Host resource, restore, service startup or publication is wired here.

- hindsight-candidate-admission.ts — Complete local v2 pair admission with paths and observed schema fixed before asynchronous reads.
- hindsight-candidate-archive.ts — Complete COPY row multiset, column and SQL file-body inventory without extraction.
- hindsight-candidate-copy-stream.ts — Streaming binary COPY validation and stable tuple multiset digests.
- hindsight-candidate-core.ts — Completed immutable Core read-back, selected closure/Pending/template and whole table inventory.
- hindsight-candidate-files.ts — Read-only regular-file, sidecar and byte-identity guards.
- hindsight-candidate-schema-admission.ts — Exact supported original version and complete source/target table-column checks.
- hindsight-candidate-profile.ts — Supported Native table families, exact source versions and classified auxiliary tables.
- hindsight-candidate-identity.ts — Physical ownership, source separation and Host-derived verifier endpoint.
- hindsight-candidate-verifier.ts — Independent restored rows and fresh v2 observation with explicit missing evidence gates.
- hindsight-candidate-refusal.ts — Closed, value-free candidate refusal vocabulary and existing backup-code mapping.
- hindsight-candidate-fixtures.ts — Generated deterministic COPY/file/SQLite fixtures pinned to the archived-Core profile; no actual Host or Native proof.
- hindsight-candidate-domain-sql.ts — Unnumbered controlling-Core schema handoff; immutable plans, requests, action fences, facts and observation receipts.
- hindsight-candidate-domain-read.ts — Validated original-candidate reads and factual local recovery projection.
- hindsight-candidate-domain-admission.ts — Transactional Memory Operation/request/candidate association and current execution guards.
- hindsight-candidate-domain-progress.ts — One-use actual Effect references and correlated stopped-resource/restore/baseline facts.
- hindsight-candidate-service.ts — Operation-facing admission, deferred claim, explicit dispatch/observation, cancellation and local-only boot recovery.
- hindsight-candidate-domain-fixture.ts — Real controlling-Core SQLite/operation/effect test fixture with generated records and physical reopen.
