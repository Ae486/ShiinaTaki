# shared/src/
- index.ts — package public entry; named re-exports of the protocol surface
- ping-schema.ts — scaffold ping/pong smoke schema (desktop IPC smoke; untouched this slice)
- json-rpc-schema.ts — JSON-RPC 2.0 envelope schemas + JSON_RPC_ERROR_CODES + JSON_RPC_APP_ERROR + client-frame union
- error-code-schema.ts — closed cross-process ErrorCode union
- connect-schema.ts — CONNECT_METHOD + RoleSchema + connect handshake param/result schemas (ADR 0004)
- chat-schema.ts — CHAT_METHODS + chat.send/cancel/delta/complete/error param & event schemas; +ImageAttachment/IMAGE_MEDIA_TYPES (in-flight image input, #17)
- timeline-schema.ts — TIMELINE_METHODS + timeline entry/part/history/subscribe/appended schemas (ADR 0005); parts = structured tool-call/result + image fidelity
- media-schema.ts — MEDIA_METHODS + media.get/clear/usage param & result schemas (attachment byte serving + lifecycle); operator-only, NO Rust mirror
- avatar-schema.ts — AVATAR_METHODS + avatar.subscribe/report/command schemas (LLM-driven expression/motion push); operator-only, NO Rust mirror
- character-schema.ts — CHARACTER_METHODS + character.import/list/costumes schemas + CharacterId slug + import-error vocabulary (#18); operator-only, NO Rust mirror
- approval-schema.ts — APPROVAL_METHODS + tool-approval request/respond schemas (MCP gate; M3 Permission Gate reuse)
- capability-schema.ts — CAPABILITY_METHODS + core↔node capability request/respond/error schemas; respond output is opaque (Option A)
- capability-outputs.ts — per-capability output schemas (Screenshot/ProcessList/ClipboardRead/ClipboardWrite/ShellOpen); mirrored in Rust serde
- ws-defaults.ts — default loopback WS host/port constants
